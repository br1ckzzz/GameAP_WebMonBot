# Чек-лист и принятые решения по проекту GameAP WebMonBot

Статус: **СОГЛАСОВАНО И ЗАФИКСИРОВАНО** (2026-09-18)

---

## 1. Структура отображения в Discord

- [x] **Вопрос 1.1: Сводный канал или отдельные темы форума?**
  - **Решение: Поддержка обоих режимов (Универсальный режим).**
    - `dashboard` (по умолчанию): Единый канал с сообщениями, сгруппированными по играм.
    - `forum`: Автоматическое создание тем в Discord Forum Channel по играм или серверам.

- [x] **Вопрос 1.2: Область действия бота?**
  - **Решение:** Автономный бот для сообщества (Single-Guild по умолчанию, с возможностью расширения).

## 2. Детализация информации о сервере в карточке

- [x] **Вопрос 2.1: Состав полей карточки сервера:**
  - Название игрового сервера.
  - Статус доступности (🟢 Онлайн / 🔴 Офлайн).
  - Текущая карта (`de_mirage`, `dust2`, etc.).
  - Прогресс-бар заполненности и онлайн: `[██████░░░░] 24/32`.
  - Адрес подключения (`IP:Port`).
  - Пинг сервера.

- [x] **Вопрос 2.2: Список ников игроков:**
  - **Решение: ИСКЛЮЧЁН (не отображается).**
  - Обоснование: Перегружает интерфейс Discord, расходует лимиты символов Embed (1024 символа на Field) и создаёт лишнюю нагрузку на трафик.

## 3. Кнопки взаимодействия (Message Components)

- [x] **Кнопка «Подключиться» (`[🔗 Подключиться]`):**
  - Отправляет эфемерное сообщение (видимое только нажавшему) с быстрой командой для консоли (`connect IP:Port`) и прямой ссылкой на подключение.
- [x] **Кнопка «Веб-мониторинг» (`[🌐 Веб-мониторинг]`):**
  - **Решение: ИСКЛЮЧЕНА (не требуется).** Карточка фокусируется исключительно на быстром подключении и обновлении, чтобы не перегружать панель кнопок.
- [x] **Кнопка «Обновить» (`[🔄 Обновить]`):**
  - Ручной триггер внеочередного опроса с кулдауном 5 секунд от спама.

## 4. Технический стек и архитектура

- [x] **Язык разработки:**
  - **Go (Golang)** с библиотекой `bwmarrin/discordgo`.
  - Преимущества: Единый статический бинарник без внешних зависимостей, потребление памяти ~15 МБ RAM, запуск как служба systemd / Windows Service / Docker.
- [x] **Хранилище состояния:**
  - Локальный JSON-файл конфигурации и состояния `state.json` (ID гильдии, каналов и сообщений).

---

## 5. Интеграция с GameAP WebMonitoring

- [x] **Безопасность и 2FA:**
  - Нулевое изменение ядра GameAP.
  - Авторизация через внутренний Read-Only токен плагина WebMonitoring (`X-WebMon-Token`).
  - Никаких админ-паролей и 2FA в боте.

---

## 6. Оповещения о событиях серверов (Выключение, Перезагрузка, Обновление)

- [x] **Вопрос 6.1: Состав отслеживаемых событий:**
  - **Выключение / Падение серверов (Offline):** Оповещение с таймстемпом и IP:порт.
  - **Запуск / Восстановление (Online):** Оповещение с указанием времени простоя (downtime).
  - **Перезагрузка (Restart):** Детекция быстрого цикла рестарта или сброса счетчиков.
  - **Обновление (Update):** Детекция изменения версии игры/билда или статуса обслуживания.
- [x] **Вопрос 6.2: Канал для отправки событий:**
  - **Решение:** Выделенный лог-канал (`alerts_channel_id`) с отдельным включением/выключением каждого типа событий.
- [x] **Вопрос 6.3: Защита от ложных срабатываний (Flapping):**
  - **Решение:** Фиксация падения только после 2–3 подряд сбойных проверок (`offline_confirm_threshold`).
