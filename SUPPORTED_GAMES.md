## 🇷🇺 Русская версия

Данный справочник содержит **полный перечень всех 297 игр** по стандарту **DiscordGSM**, поддерживаемых игровых серверов, их системные коды и команды для использования в Discord-боте **GameAP WebMonBot**.

Вы можете использовать как **короткий код** (`cs2`, `samp`, `bedrock`, `valheim`, `mc`), так и **полное название** игры в командах:
- Добавить внешний сервер: `/mon add address:185.12.34.56:7777 game:samp`
- Привязать игру к каналу: `/mon bind game:cs2 channel:#cs2`
- Отвязать игру от канала: `/mon unbind game:cs2`

Игры отсортированы строго в алфавитном порядке (A–Z).

## 🇬🇧 English Version

This reference directory lists **all 297 supported multiplayer game servers** based on the **DiscordGSM** standard, their system identifiers (codes), and aliases used by the **GameAP WebMonBot**.

You can use either the **short code** (`cs2`, `samp`, `bedrock`, `valheim`, `mc`) or the **full game name** in bot commands:
- Add standalone server: `/mon add address:185.12.34.56:7777 game:samp`
- Bind game to channel: `/mon bind game:cs2 channel:#cs2`
- Unbind game from channel: `/mon unbind game:cs2`

All 297 games are indexed alphabetically (A–Z) in the table above.
